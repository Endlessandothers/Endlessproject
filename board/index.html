How these numbers are counted

  • Demand is distinct callers, not requests. One caller asking the same thing five hundred ways counts once.
  • Needs are grouped by meaning, not wording, so rephrasing a question does not make it look like a second person asking.
  • Callers are verified. Only requests carrying a key proved against a stored hash are counted. Anything self-declared is not.
  • Distinct owners are counted too, so one person holding ten keys is one voice, not ten.
  • Whoever closes a need does not get to have voted for it. Their own requests are removed from the evidence before any reward.
  • Identities are never published. Counts only.
